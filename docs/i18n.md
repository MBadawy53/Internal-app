# Internationalization (i18n)

The portal ships **EN + AR with full RTL parity**. Adding a new language requires three steps; adding a new string requires one.

## Adding a string

1. Add the key + value to `messages/en.json`.
2. Add the same key with the Arabic translation to `messages/ar.json`.
3. Use it in code:

   ```tsx
   // Server Components
   import { getTranslations } from "next-intl/server";
   const t = await getTranslations("dashboard");
   t("title", { name });

   // Client Components
   import { useTranslations } from "next-intl";
   const t = useTranslations("dashboard");
   ```

## Switching locale

- The user toggles via `LocaleToggle` in the top bar.
- Cookie `contact_locale` persists the choice.
- For authenticated users, the `User.locale` column is also updated, so a fresh login on a new device honors the preference.

## RTL gotchas

- The `<html dir>` attribute is set in `RootLayout` based on locale. Tailwind responds with the `rtl:` variant.
- Use **logical CSS properties** where possible: `ms-*` (margin-start), `me-*` (margin-end), `ps-*`, `pe-*`, `start-*`, `end-*`. Avoid `ml-*`, `mr-*`, `left-*`, `right-*`.
- Icons that imply direction (arrows, chevrons) should be wrapped or have `rtl:rotate-180` applied — never hardcode "previous = left".
- Charts (Phase 6): set `direction="rtl"` on the chart container; mirror axes manually for true RTL.

## Numbers, currency, dates

- **Currency** is **EGP** by default. The `Money` value object (`src/lib/finance/money.ts`, Phase 2) handles formatting with the active locale.
- **Numbers**: use `Intl.NumberFormat(locale)` — Arabic-Indic digits render automatically when locale is `ar-EG`.
- **Dates**: use `date-fns` with `enGB` and `arEG` locales (added in Phase 2).

## Adding a new language

1. Add a new file `messages/<locale>.json` with translated keys.
2. Append the locale code to `SUPPORTED_LOCALES` in `src/lib/i18n/config.ts`.
3. Update the `Locale` enum in `prisma/schema.prisma` and migrate.
4. Add the option to `LocaleToggle`.

## Fonts

- Latin: **Inter**, loaded via `next/font/google`.
- Arabic: **IBM Plex Sans Arabic**, loaded via `next/font/google`.
- The body's `font-family` switches automatically based on `<html dir>` (see `globals.css`).
